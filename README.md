# RendezVous.tn — maquette de test

Version de test de la maquette RendezVous.tn, protégée par mot de passe, publiée sur GitHub Pages pour les testeurs.

- Adresse : https://elyesg.github.io/rendezvous-test/
- `index.html` contient la maquette chiffrée (AES-GCM, clé dérivée du mot de passe par PBKDF2). Sans le mot de passe, son contenu est illisible.
- La source de la maquette est dans le dépôt privé `rendezvous`, dans `docs/legacy/maquette-rendezvous-tn.html`.

C'est une maquette : les données sont fictives et rien n'est envoyé à un serveur.
